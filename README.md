# 2much

Учебный frontend-проект интернет-магазина кофе и аксессуаров.

## Этап

Практика 2 - семантическая страница и базовые стили.

## Просмотр и структура

Откройте `index.html` в браузере. Стили находятся в `css/style.css`, иллюстрации - в `images/`.

## Технологии

HTML, CSS, Git, GitHub.

## Постановка контрольной работы №1

Тема: «HTML и CSS: разработка многостраничного сайта». Итоговая версия должна включать главную, каталог, карточку товара, заявку, контакты, навигацию и общий CSS.
