# 2much

Заряд настроения на весь день.

Учебный многостраничный магазин кофе и аксессуаров.

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».
Дисциплина: «Фронтенд и бэкенд разработка», 3 семестр.

Проект помогает выбрать кофе по способу приготовления, прочитать характеристики и заполнить демонстрационную заявку. Реальные заказы, платежи и передача данных отсутствуют. Цены, сведения о товарах и контакты демонстрационные.

## Просмотр

Откройте `index.html` в современном браузере. Установка пакетов и сборка не требуются. Все изображения и стили находятся внутри проекта, интернет для просмотра основного сайта не нужен (Bootstrap-версии в `kr2-bootstrap/` он нужен — Bootstrap подключён через CDN).

Для проверки через HTTP можно открыть папку в VS Code и использовать Live Server. Альтернатива при установленном Python:

```sh
python -m http.server 8000
```

Затем откройте `http://localhost:8000/`. Фильтрация каталога использует CSS `:has()` и рассчитана на современный браузер.

## Обязательные страницы

- Главная: первый экран, преимущества, популярные товары, ссылка на гид.
- Каталог: шесть карточек, категории, фильтр, блок ответов на вопросы.
- Товар: изображение, описание, цена, таблица характеристик, кнопка заявки.
- Заявка: имя, e-mail, телефон, дата связи, выбранный товар, комментарий и согласие.
- Контакты: демонстрационные контактные сведения и переход к заявке.

## Технологии и решения

- HTML5: семантические области, один `main` на страницу, `article`, `aside`, таблицы и нативный `dialog`.
- CSS: переменные в `:root`, общая шкала отступов, Flexbox, Grid, БЭМ, медиазапросы.
- Состояния: `:hover`, `:focus-visible`, `:disabled`, `[aria-invalid="true"]`.
- Позиционирование: `relative` у карточек, `absolute` у бейджей, `sticky` у шапки и фильтра, `fixed` у ссылки «Наверх», `z-index` для слоёв.
- JavaScript без библиотек: открытие и закрытие окна, передача товара в форму, проверка полей и демонстрационное подтверждение.

## Доработки сверх базовой инструкции

- Собственная визуальная концепция: бумажная палитра, терракотовый акцент, типографическая иерархия и локальная предметная графика.
- Отдельные страницы всех шести товаров с собственными характеристиками.
- Гид с выбором зерна и тремя рецептами.
- Фильтрация категорий без JavaScript через радиокнопки и `:has()`.
- Хлебные крошки, якорные ссылки, переход к полной заявке с выбранным товаром.
- FAQ на нативных `details` и `summary`.
- Бейджи, категории, данные об упаковке и состояние отсутствующего товара.
- Ошибки рядом с полями, общий итог проверки, перевод фокуса к ошибке и подтверждению, возврат фокуса после закрытия окна.
- Ссылка пропуска навигации, видимый фокус, `prefers-reduced-motion`, подписи таблиц и полей.
- Базовая поддержка узких экранов.

## CSS-архитектура

В `style.css` последовательно расположены переменные, базовые правила, состояния, шапка, главная страница, карточки и каталог, товар и таблица, формы, дополнительные разделы, подвал, медиазапросы. Компоненты имеют классы вроде `product-card`, `product-card__title`, `product-card--unavailable`.

Повторяемые шапка, подвал и форма присутствуют в статических HTML-файлах намеренно: проект работает без шаблонизатора и сборки. Общий внешний CSS и один JS-файл используются на всех страницах.

## Проверка формы

1. Нажмите «Заказать» на карточке: товар уже выбран в окне.
2. Отправьте пустую форму: появятся ошибки, фокус перейдёт к первому полю.
3. Проверьте неправильную почту, короткое имя и телефон другого формата.
4. Заполните имя, почту, телефон `+7 (900) 123-45-67`, выберите товар, отметьте согласие.
5. После отправки окно закроется, поля очистятся, появится сообщение «Форма успешно отправлена!» с пояснением демонстрационного режима.
6. Окно закрывается кнопкой и клавишей Escape. Tab перемещает фокус между доступными элементами.

Дата и комментарий необязательны. Никаких запросов с данными формы, cookie, аналитики и внешних шрифтов нет.

## Контрольная работа №2 — Bootstrap (практические №9–11)

Папка `kr2-bootstrap/`. Bootstrap 5.3.3 подключён через CDN (CSS в `head`, JS Bundle с `defer`), после него — собственный `css/custom.css`. Для просмотра нужен интернет.

- **Все страницы:** единый `navbar navbar-expand-lg` с кнопкой-бургером (`navbar-toggler`) и ссылкой на основной сайт, ссылка пропуска, один `h1`, подвал.
- **Сетка:** `container`, `row`, `col-12 col-md-6 col-lg-4`, отступы `g-4`, `my-5`, `mb-*`, `p-4`.
- **Главная:** hero на сетке (`col-12 col-lg-6`, `img-fluid`), блок преимуществ, сетка популярных товаров из `card`.
- **Каталог:** карточки с `badge` и `btn`, вкладки `nav-tabs` (Кофе / Посуда), `carousel`, `alert`.
- **Товар:** `breadcrumb`, таблица `table table-striped` в `table-responsive`, модальное окно `modal`, FAQ на `accordion`.
- **Заявка:** `form-control`, `form-select`, `input-group` (телефон с +7), `form-check` (согласие), `invalid-feedback`; проверка через `was-validated`, сообщение об успехе — `alert alert-success`, без `alert()`.
- **custom.css:** фирменный терракотовый цвет через CSS-переменные переопределяет `--bs-primary` и кнопки.

## Контрольная работа №3 — адаптивность и доступность (практические №12–14)

### Адаптивные решения

- **Mobile First:** `css/responsive.css` подключён на всех 12 страницах после `style.css`. Базовые стили рассчитаны на 320–767 px, дальше медиазапросы `min-width` 768 / 1024 / 1440 px.
- **Шапка:** на телефоне меню переносится на вторую строку, с 768 px всё в одну строку. Высота ссылок не меньше 44 px.
- **Hero:** на телефоне одна колонка, заголовок `clamp()`, с 1024 px две колонки.
- **Карточки товаров:** 1 → 2 (768 px) → 3 (1024 px) колонки.
- **Каталог:** на телефоне фильтр сверху, с 1024 px — боковая панель (`sticky`).
- **Изображения:** `max-width: 100%`, `height: auto`. Hero — через `<picture>` с упрощённой картинкой для телефона, карточки — `srcset` + `sizes` (`*-small.svg` 320w и полная версия).
- **Форма заявки:** поля на всю ширину, на телефоне одна колонка, с 768 px — две.
- **Таблица характеристик:** обёртка `.table-wrap` с `overflow-x: auto`.
- **Проверено:** ширины 360, 430, 768, 1024, 1440 px — горизонтальной прокрутки нет ни на одной странице.

### Доступность

- Ссылка «Перейти к содержимому» ведёт на `#main` на всех страницах.
- Видимый фокус: `:focus-visible`, рамка 3 px.
- Минимальный размер текста поднят до 12 px (навигация 14 px).
- Размер зон нажатия в меню, фильтрах и форме — не меньше 44 px.
- Семантика: `header`/`nav`/`main`/`footer`, `label for` у полей, `aria-describedby` для ошибок, `caption` и `th scope` у таблиц, `aria-current` у текущей страницы.
- Кнопки — для действий, ссылки — для переходов. Модальное окно — нативный `dialog` с `aria-labelledby`, закрывается Escape, фокус возвращается.
- ARIA используется только там, где HTML не справляется (`aria-hidden` у декоративных иконок, `aria-live` у статистики каталога).

### Lighthouse

Аудит Lighthouse 12 (Chrome, локальный сервер `python -m http.server`). Отчёты лежат в `docs/lighthouse/`: откройте `*.report.html` в браузере.

| Страница | Производительность | Доступность | Лучшие практики | SEO |
|---|---|---|---|---|
| `index.html` | 100 | 100 | 100 | 100 |
| `catalog.html` | 100 | 100 | 100 | 100 |

Найдено и исправлено: в каталоге после `h1` сразу шли заголовки карточек `h3`, то есть был нарушен порядок заголовков. Добавлен заголовок `h2` «Товары» с классом `.visually-hidden`: его не видно на экране, но его читают экранные дикторы. После исправления доступность каталога выросла с 98 до 100.

Осталось замечание `label-content-name-mismatch` (не влияет на оценку): `aria-label` у логотипа и ссылок-картинок карточек не совпадает с видимым текстом. Это можно исправить при следующей доработке.

## Практические №15–16 — JavaScript

- `js/data.js` — данные: объект `product` и массив `products` из 8 товаров с одинаковой структурой (`id`, `title`, `category`, `price`, `discountPercent`, `rating`, `isAvailable`).
- `js/main.js` — функции. Оба файла подключены с `defer`, `data.js` — раньше `main.js`.
- **№15 (один товар):** `formatPrice`, `calculateDiscount`, `calculateFinalPrice`, `getProductStatus`, `createProductSummary`. Результат выводится на странице `product.html` в блок `#product-summary`.
- **№16 (массив товаров):** `getProductTitles`, `getAvailableProducts`, `searchProducts`, `filterProductsByCategory`, `sortProductsByPrice`, `findProductById`, `calculateTotalPrice`, `countAvailableProducts`, `calculateAveragePrice`, `getPreparedProducts` (поиск + категория + сортировка). Используются `map`, `filter`, `find`, `sort`, `reduce`, условия и циклы.
- Результаты видны в консоли браузера (F12 → Console), сгруппированы по занятиям. Краткая статистика выводится на странице каталога в блок `#catalog-stats`.
- **Основа проекта:** использован сайт КР №1, дополненный КР №3.

### Безопасный вывод данных

Данные выводятся на страницу только через `textContent`, а не через `innerHTML`. `innerHTML` воспринимает строку как HTML-код, и если в данных окажется `<script>` или вредоносный атрибут, он выполнится. `textContent` всегда показывает строку как обычный текст. Код также проверяет, что нужный элемент и массив товаров существуют, поэтому на других страницах ошибок нет.
